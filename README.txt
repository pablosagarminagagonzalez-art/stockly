STOCKLY - INVENTARIO WALLAPOP (PWA)

Incluye:
- Alta de compras y artículos en stock
- Registro de ventas, comisiones y beneficio neto
- Inventario con búsqueda y filtros
- Resumen y estadísticas por mes/categoría
- Exportación CSV
- Persistencia local en el navegador (localStorage)
- Caché offline mediante Service Worker

IMPORTANTE: para instalarla como PWA en iPhone, los archivos deben estar publicados en una dirección HTTPS. La forma más sencilla y gratuita es GitHub Pages o Netlify. No requiere cuenta ni integración con Wallapop.

INSTALACIÓN EN IPHONE:
1. Publica el contenido de esta carpeta en un hosting HTTPS (por ejemplo GitHub Pages).
2. Abre la URL publicada en Safari.
3. Pulsa Compartir > Añadir a pantalla de inicio > Añadir.
4. Abre Stockly desde el icono de la pantalla de inicio.

DATOS Y COPIAS:
Los datos se guardan en el almacenamiento local del navegador de ese iPhone. No se sincronizan automáticamente con otros dispositivos. Usa el botón de exportar para descargar un CSV de movimientos con regularidad. Evita borrar los datos del sitio en Safari.

La aplicación no se conecta a Wallapop ni importa operaciones automáticamente; los datos se introducen manualmente.
